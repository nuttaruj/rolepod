<!-- Load when the work hits steps only the HUMAN can perform — provisioning -->
<!-- a third-party service, minting credentials / CI secrets, walking a -->
<!-- vendor dashboard, approving a plugin, a one-off cutover. Never for -->
<!-- steps the agent can run itself. -->

Some tasks contain a stretch the agent cannot cross: values that only exist
behind a login, buttons only a human may click, approvals only the user can
grant. The default failure is a wall of chat instructions the user scrolls,
half-follows, and re-asks next month. A **setup wizard** replaces that wall
with an executable: a bash script that walks the user stage by stage — opens
each URL, says exactly what to copy, captures the value with hidden entry
when secret, writes it where it belongs (`.env`, `gh secret`), and confirms
before anything irreversible.

Disposable by default: write it to the scratch dir or `scripts/`, run once,
delete. Commit it only when the procedure will repeat (team onboarding, a
setup path worth keeping) — then link it from the README.

## Procedure

1. **Scope from the repo, not from memory.** Enumerate the manual steps and
   the values they produce: read `.env.example`, `.env.*`, README,
   docker-compose, framework config, and `.github/workflows/*` — every
   `secrets.*` / `vars.*` reference is a value the wizard must produce. For
   a cutover: current state, target state, the irreversible actions between.
   Show the user the ordered stage list + captured values; they reorder or
   cut before you write a line.
2. **Trace each stage like a stranger will follow it.** Exact path:
   "Dashboard → Developers → API keys → Reveal → copy". A UI you have not
   verified is a question for the user or the vendor docs — per
   verify-first, never invent clicks that may not exist.
3. **Author from the template below.** One `stage` block per step in
   dependency order; set `TOTAL_STAGES`. The helper library is fixed — edit
   only below the `# ── STAGES` marker.
4. **Verify statically, never end-to-end.** The script blocks on human
   input and opens browsers — running it is the user's move. Your checks:
   `bash -n`, `shellcheck` if present, `chmod +x`, and a trace that every
   scoped value is captured and lands where step 1 said (each `set_secret`
   name must match a `secrets.*` reference in CI exactly).

Rules the template already encodes — keep them when authoring stages: open
the URL **before** asking for its value; `ask_secret` for anything secret;
`confirm` before every irreversible action; one focused task per stage.

## Template

Write this to the target path, then replace the example stage:

```bash
#!/usr/bin/env bash
# <name> — interactive setup wizard (generated by rolepod implement-plan).
# Walks a human through steps only they can perform. Run: bash <this-file>
set -euo pipefail

TOTAL_STAGES=1   # keep in sync with the stage calls below
CURRENT=0
CAPTURED=()

B=$'\033[1m'; C=$'\033[36m'; Y=$'\033[33m'; N=$'\033[0m'

stage() {           # stage "<title>"
  CURRENT=$((CURRENT + 1))
  clear
  printf '%s[%d/%d] %s%s\n\n' "$B" "$CURRENT" "$TOTAL_STAGES" "$1" "$N"
}
say()  { printf '%s\n' "$*"; }
step() { printf '  %s→%s %s\n' "$C" "$N" "$*"; }

open_url() {        # open_url <url> — macOS / Linux / WSL
  printf '  %sopening%s %s\n' "$Y" "$N" "$1"
  if command -v open >/dev/null;        then open "$1"
  elif command -v wslview >/dev/null;   then wslview "$1"
  elif command -v xdg-open >/dev/null;  then xdg-open "$1"
  else say "  (open manually: $1)"; fi
}

ask() {             # ask VAR "prompt"
  local var="$1"; shift
  read -r -p "  $* : " "${var?}"
}
ask_secret() {      # ask_secret VAR "prompt" — hidden entry
  local var="$1"; shift
  read -r -s -p "  $* (hidden): " "${var?}"; echo
}

write_env() {       # write_env KEY VALUE [file] — idempotent upsert
  local key="$1" val="$2" f="${3:-.env}"
  touch "$f"
  if grep -q "^${key}=" "$f"; then
    tmp=$(mktemp) && grep -v "^${key}=" "$f" > "$tmp" && mv "$tmp" "$f"
  fi
  printf '%s=%s\n' "$key" "$val" >> "$f"
  CAPTURED+=("$key → $f")
}
set_secret() {      # set_secret NAME VALUE — GitHub Actions secret
  gh secret set "$1" --body "$2" && CAPTURED+=("$1 → gh secret")
}
set_var() {         # set_var NAME VALUE — GitHub Actions variable
  gh variable set "$1" --body "$2" && CAPTURED+=("$1 → gh variable")
}

pause()   { read -r -p "  [enter] when done "; }
confirm() {         # confirm "about to X" — gate irreversible actions
  read -r -p "  ${Y}CONFIRM${N} $1 — type yes: " a
  [ "$a" = "yes" ] || { say "  aborted."; exit 1; }
}

# ── STAGES — everything above is fixed; author below ──────────────────

stage "Example: API key"
step "Log in and reveal the test key"
open_url "https://example.com/dashboard/api-keys"
ask_secret API_KEY "paste the key"
write_env EXAMPLE_API_KEY "$API_KEY"

# ── summary ───────────────────────────────────────────────────────────
clear
printf '%sdone — %d value(s) captured%s\n' "$B" "${#CAPTURED[@]}" "$N"
for c in "${CAPTURED[@]}"; do say "  $c"; done
```
