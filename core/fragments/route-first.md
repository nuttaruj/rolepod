## Route first

Every commission (fix / add / change / build, follow-ups too): tier it in
ONE line before the first edit — R0 answer only · R1 trivial edit · R2 one
file + test · R3 multi-file · R4 high-risk. Blast radius sets the tier,
not the feature's age; effort settings raise thinking, not the tier.
R2-R4 → load `using-rolepod` before reading code; it names the first
skill and its owner.
